# Jiawei Li | Personal Portfolio

A modern personal portfolio and technical profile page built with React, TypeScript, Vite, and Material UI.

## About This Project

This repository is the codebase for my personal portfolio website — a polished landing page that presents my background, technical interests, selected projects, and contact information in a clean and modern style.

It is designed to feel like a personal technology blog / portfolio homepage, combining:

- strong visual hierarchy
- premium product-style presentation
- responsive layout for mobile and desktop
- bilingual content support
- smooth scroll-based reveal effects
- clear emphasis on projects, skills, and experience

## Highlights

- Portfolio landing page with a refined editorial look
- React + TypeScript front-end architecture
- Material UI-based design system
- Data-driven content structure for easy updates
- Lightweight Vite development workflow

## Tech Stack

- React 19
- TypeScript
- Vite
- Material UI
- Emotion

## Local Development

### Install dependencies

```bash
npm install
```

### Start the dev server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Content Customization

Most portfolio content is stored in `src/data.ts`, while the page structure and visual composition live in `src/App.tsx`.

Common content updates include:

- profile summary and introduction
- experience timeline
- projects and case studies
- technical skills and tools
- social links and contact details
