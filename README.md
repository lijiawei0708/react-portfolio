# Jiawei Li — React Portfolio

A responsive personal portfolio site built with React, TypeScript and Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build for production

```bash
npm run build
```

The production files will be generated in `dist/`.

## Customise

Most resume/portfolio content lives in:

- `src/data.ts`

Main layout:

- `src/App.tsx`

Styling:

- `src/styles.css`

You can add LinkedIn/GitHub links inside the contact section in `src/App.tsx`.
